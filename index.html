คู่มือใช้งาน

ผู้ปกครอง: เข้าหน้าแรก กด "สมัครเรียนออนไลน์" กรอกข้อมูลแล้วส่ง จะได้รหัสใบสมัครและพิมพ์ใบสมัครได้ทันที หากทำหายสามารถค้นหาด้วยรหัสใบสมัครและเลขประจำตัวประชาชนนักเรียน
เจ้าหน้าที่: เข้าสู่ระบบที่แท็บ "เจ้าหน้าที่" · แท็บ "รายงาน/พิมพ์" ค้นหา/กรองใบสมัคร กด "พิมพ์" เพื่อพิมพ์รายบุคคล (2 หน้า A4) หรือติ๊กเลือกหลายคนแล้ว "พิมพ์ที่เลือก" · ปุ่ม "ตรวจ" บันทึกผลตรวจหลักฐาน (ครบ/ขาด) ซึ่งจะพิมพ์ท้ายใบสมัคร · "พิมพ์แบบฟอร์มเปล่า" สำหรับกรอกด้วยมือ · "ส่งออก Excel" ได้ไฟล์ .xlsx
ตั้งค่า: ข้อมูลโรงเรียน/ตรา/ประกาศ/เปิด-ปิดรับสมัคร · รายชื่อนักเรียน (นำเข้า Excel ได้) · ผู้ใช้งาน (ผู้ดูแลระบบ) · เชื่อมต่อ GitHub และสำรองข้อมูล (ผู้ดูแลระบบ)
นำข้อมูลจากระบบ Offline มาใช้: ตั้งค่า → เชื่อมต่อ/สำรองข้อมูล → "กู้คืน / นำเข้าจากระบบ Offline" เลือกไฟล์สำรอง .json เดิม
